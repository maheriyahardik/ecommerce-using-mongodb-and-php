 Electronic Store – Web-based E-commerce Platform
A full-stack web application built using PHP and MongoDB for managing an online electronic products store.

This project features a user-friendly interface for customers to browse, search, and purchase electronic items, and a robust admin dashboard for managing products, categories, orders, inventory, and users.

🔍 Features
🛒 User Side:
🏠 Home Page: Browse available products.

👤 Profile Page: View personal user information.

🛍️ Cart Page: Add, update, and remove selected products.

📦 Order Page: Track and view past orders.

ℹ️ About Page: Information about the store.

🔐 Login Page: User authentication.

🚪 Logout Page: Secure session logout.

⚙️ Admin Side:
📊 Admin Dashboard: Overview and quick insights.

📁 Category & Sub-category Management.

📦 Product & Inventory Management.

🔍 Product Search Functionality.

👥 User Management.

🛒 Cart Monitoring and Management.

📑 Order Management.

🛠️ Tech Stack
Backend: PHP

Database: MongoDB

Frontend: HTML, CSS, JavaScript
